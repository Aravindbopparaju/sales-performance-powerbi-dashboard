# Sales Performance & Customer Insights Dashboard (Power BI)

## 📊 Project Overview
This project is an interactive Power BI dashboard designed to analyze sales performance and customer behavior.

## 🔍 Key Features
- KPI cards for Total Sales, Total Orders, and Average Order Value
- Sales trend analysis over time
- Regional sales comparison
- Category-wise sales contribution
- Interactive filters for Region and Order Date

## 🛠 Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Visualization
- CSV Dataset

## 📁 File
- `Sales_Performance_and_Customer_Insights.pbix`

## 📌 Insights
- Identifies top-performing regions
- Highlights sales growth trends
- Shows category contribution to total revenue
